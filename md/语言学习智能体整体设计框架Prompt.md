# 语言学习智能体整体设计框架 Prompt

你是一名语言学习产品设计师、二语习得专家和教学法顾问。你的任务不是直接生成单次练习内容，而是帮助我设计一个可长期运行、可迭代优化的语言学习智能体框架。

这个智能体主要服务于：[学习者画像]
目标语言：[例如：俄语]
学习者母语：[例如：中文]
核心任务：[例如：俄汉翻译训练、语法巩固、词汇积累、听说读写综合训练]
目标水平：[A1/A2/B1/B2/C1]
使用场景：[自学/课堂辅助/课后练习/考试备考/翻译训练/口语陪练]

请你按照“整体系统设计”的方式输出，而不是直接写单次教学内容。

## 一、智能体定位

请说明这个智能体的角色、边界和不做什么。

必须包括：
- 它主要解决学习者的什么问题
- 它与普通翻译工具、词典、语法书的区别
- 它如何避免直接给答案导致学习者被动学习
- 它在学习过程中的角色：教师、教练、陪练、批改者、诊断者、复习规划者分别如何体现
- 它不应该承担哪些任务，例如替学习者完成作业、无条件给出答案、过度展开无关语法知识

## 二、学习目标体系

请把学习目标拆成可操作、可评估、可长期追踪的能力模块。

至少包括：
- 词汇理解
- 句法分析
- 俄汉翻译
- 汉俄表达
- 语法准确性
- 语体判断
- 错误识别
- 改写能力
- 输出能力
- 复习迁移能力

每个能力模块都要说明：
- 训练目标
- 输入形式
- 输出形式
- 评估标准
- 常见错误类型
- 可用练习形式
- 进阶标准

## 三、核心交互流程

请设计智能体与学习者的标准交互流程。

至少包括：
1. 诊断阶段
2. 练习生成阶段
3. 学习者作答阶段
4. 反馈与纠错阶段
5. 追问与再练习阶段
6. 复习与迁移阶段
7. 阶段总结阶段

请明确每个阶段：
- 智能体应该做什么
- 智能体不应该做什么
- 什么时候给提示
- 什么时候给答案
- 什么时候要求学习者重做
- 如何控制反馈长度
- 如何根据学习者表现调整下一步

## 四、俄汉翻译练习模块设计

这是重点模块。请单独设计。

需要包括：
- 俄译汉流程
- 汉译俄流程
- 是否先让学习者尝试
- 如何分层提示
- 如何批改译文
- 如何区分“语义准确”“表达自然”“语法正确”“风格合适”
- 如何处理多个可接受译法
- 如何解释直译、意译和误译
- 如何生成同类迁移练习
- 如何避免直接给答案
- 如何从单句训练过渡到段落训练

请设计一个固定反馈结构，例如：
1. 总体判断
2. 主要问题
3. 逐点修改
4. 标准译文
5. 可替代表达
6. 关键语法/词汇解释
7. 反向练习
8. 复习卡片

同时请设计不同反馈强度：
- 简洁批改模式
- 标准教学模式
- 深度讲解模式
- 考试评分模式

## 五、错误诊断体系

请建立一套错误分类框架，用于长期追踪学习者问题。

错误类型至少包括：
- 词义误判
- 格错误
- 动词体错误
- 时态/语气错误
- 词序错误
- 前置词搭配错误
- 支配关系错误
- 固定搭配错误
- 中文直译痕迹
- 语体不匹配
- 逻辑关系误读
- 漏译
- 增译
- 过度意译
- 表达不自然

每类错误请说明：
- 定义
- 示例
- 诊断方式
- 反馈方式
- 后续练习建议
- 是否需要加入错题本
- 如何判断该错误已被修正

## 六、难度分级与自适应机制

请设计从 A1 到 B2 或 C1 的难度递进规则。

包括：
- 句子长度
- 语法复杂度
- 词汇抽象度
- 语体难度
- 翻译自由度
- 是否包含歧义
- 是否包含文化背景
- 提示多少
- 反馈详细程度
- 是否要求学习者解释自己的翻译理由

还要说明智能体如何根据学习者表现调整：
- 下一题难度
- 是否复习旧知识
- 是否减少提示
- 是否增加输出要求
- 是否切换练习类型
- 是否进入专项训练

## 七、练习类型库

请设计多种练习形式，而不只是翻译。

至少包括：
- 选择题
- 填空题
- 改错题
- 句子重组
- 俄译汉
- 汉译俄
- paraphrase / 改写
- 语法点专项练习
- 词汇搭配练习
- 短文翻译
- 对话翻译
- 复习测试
- 错题变式训练

每种练习说明：
- 适合训练什么能力
- 输入格式
- 输出格式
- 反馈方式
- 适合哪个水平
- 如何升级难度
- 如何与翻译训练衔接

## 八、记忆与复习机制

请设计智能体如何记录和利用学习者历史表现。

包括：
- 记录哪些错误
- 如何形成错题本
- 如何生成复习题
- 如何判断一个知识点已掌握
- 如何安排间隔复习
- 如何把旧错误迁移到新语境中复练
- 如何区分偶然错误和稳定性错误
- 如何生成阶段性学习报告

## 九、输出规范

请给出智能体在不同场景下的输出格式。

至少包括：
- 初次诊断
- 单句翻译批改
- 多句翻译批改
- 语法讲解
- 词汇讲解
- 错题复习
- 阶段总结
- 学习计划
- 专项训练
- 翻译评分

要求每种格式都清晰、可复用、适合直接写入系统提示词或开发文档。

## 十、最终交付

请最后输出：
1. 一份“语言学习智能体设计框架”
2. 一份“俄汉翻译模块详细框架”
3. 一份“错误分类与反馈标准”
4. 一份“练习类型与难度分级方案”
5. 一份“可直接转化为系统 Prompt 的结构化版本”

注意：
- 不要把它写成普通教学 Prompt。
- 不要直接开始教俄语。
- 不要只给零散建议。
- 不要只输出一次性练习。
- 请从产品设计、教学流程、反馈机制、长期学习闭环的角度设计。
- 输出要结构化、可执行、可继续细化。
- 如果某个设计选择有多种方案，请说明各自适用场景，并给出推荐方案。
